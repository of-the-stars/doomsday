# Doomsday

This is a little CLI game meant to run right after I login to practice the [Doomsday algorithm](https://en.wikipedia.org/wiki/Doomsday_rule), similarly to how [John H. Conway](https://en.wikipedia.org/wiki/John_Horton_Conway) is said to have done so.

## Background

I was first introduced to the algorithm when I watched [this video](https://www.youtube.com/watch?v=714LTMNJy5M) when I was younger. I groked it pretty quickly, but besides remembering the doomdays of a year, I kept forgetting the formula to get a particular year's doomsday. Back when I first saw it, I was yet to have gotten as deep into Linux as I am now. 

When I realized that I'm at a point where I can pretty much make my computer do anything I want however I want it to, I decided that it would be a good idea to try and implement the game to practice whenever I log into my machine. It would be good practice, both to encourage frequent mental arithmetic, and to implement the algorithm programmatically.
